# POO---Evoka-
Projeto acadêmico de Programação Orientada a Objetos (POO) que desenvolve a parte de programação da plataforma SPRINTA, voltada para corredores de rua. A aplicação centraliza informações sobre pontos de apoio, estabelecimentos parceiros e acompanhamento de treinos, promovendo praticidade, conforto e segurança durante a corrida.
